# Lesson 7: Skill, Hook, Subagent, or CLAUDE.md?

Choosing the right layer for recurring team capabilities.

- **CLAUDE.md**: Global project rules always present in context.
- **Skill**: On-demand capability triggered by specific user prompts or tasks.
- **Hook**: Automated event handler (e.g., pre-commit, post-tool execution).
- **Subagent**: Isolated worker process with custom system prompt and tools.
