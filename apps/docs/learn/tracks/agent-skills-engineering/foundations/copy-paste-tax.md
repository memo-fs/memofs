# Lesson 2: The Copy-Paste Tax

Stop retyping prompt instructions and checklists into coding agents on every single task.

## The Problem
Developers spend up to 20% of their coding time re-prompting AI agents with contextual guidelines, linting rules, and review constraints.

## The Solution
A directory with a `SKILL.md` file defines reusable capability modules that agents discover and load automatically when relevant.
