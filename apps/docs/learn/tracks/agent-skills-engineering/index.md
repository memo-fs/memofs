# Lesson 1: Overview — Agent Skills Engineering

Welcome to the **Agent Skills Engineering** track. In this track, you will build one real, functional Agent Skill from an empty folder to an org-wide deployment — writing the `SKILL.md`, engineering a description that reliably triggers, bundling scripts and reference files, locking down tool access, wiring it into an isolated subagent, distributing it via git and plugins, and diagnosing every way it can fail.

## Course Objectives

- Understand the open Agent Skills architecture (Claude Code, Codex, Cursor, and Agentic SDKs).
- Learn how progressive disclosure selects instructions dynamically to save token budgets.
- Package scripts, utilities, and reference materials into reusable skill packages.
- Restrict and leash skills to guarantee safe execution across engineering teams.
