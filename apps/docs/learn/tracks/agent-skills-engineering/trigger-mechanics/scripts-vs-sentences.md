# Lesson 5: Scripts vs Sentences

Do not write prose instructions for tasks that can be deterministically executed by a script.

## Rules of Thumb
- Use **Scripts** for deterministic tasks: parsing ASTs, checking git diffs, running linter checks.
- Use **Sentences** for semantic tasks: explaining tradeoffs, recommending architectural changes.
