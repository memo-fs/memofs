# Lesson 4: The Description Is the Trigger

The `description` field in frontmatter acts as the intent classifier for your skill.

## Best Practices
- Include concrete verbs and trigger keywords (e.g. `Use when asked to generate migrations...`).
- Avoid vague descriptions like `Helps with code`.
