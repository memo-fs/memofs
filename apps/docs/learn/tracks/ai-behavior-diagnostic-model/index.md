# Lesson 1: Overview — AI Behavior: A Diagnostic Model

Build a repeatable mental model for diagnosing why AI agent outputs drift or fail, and how to systematically fix them.

## Overview

When an AI agent gives a wrong, incomplete, or unexpected response, guessing at random prompt edits often makes the behavior worse. This track establishes a systematic 4-property diagnostic framework:

1. **Next-Token Prediction**: Understanding generation mechanics and sampling dynamics.
2. **Knowledge Boundaries**: Training cutoffs vs parametric knowledge density.
3. **Working Memory Limits**: Attention degradation and context window management.
4. **Steerability**: Effective prompt constraints vs instruction overload.
