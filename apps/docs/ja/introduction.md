# MemoFS とは？

MemoFS は、**AI エージェント向けファイルファーストのメモリランタイム**です。日常的に**コーディングエージェントを使用する**開発者と、**AI エージェントアプリケーションを構築する**開発者の両方に最適化されています。

このドキュメントのすべての内容は、1 つのシンプルな問いから始まります：**「MemoFS をどのように活用しますか？」**

## あなたに最適なパスはどれですか？

### 日常的にコーディングエージェントを利用する
Claude Code、Cursor、Codex、Copilot、opencode、またはその他の AI コーディングエージェントは、MCP (Model Context Protocol) またはライフサイクルフックを介して MemoFS のメモリを自動的に読み書きできます — セットアップは 5 分以内で完了します。

→ **[クックブックでお使いのエージェントを探す](/learn/cookbooks/)**

→ **[MCP サーバーの概要](/mcp/)**

### AI エージェント & アプリケーションを構築する
`@memofs/core` または `@memofs/server` を直接インポートして、軽量でファイルファースト、データベース不要のメモリランタイムをカスタムエージェントに組み込みます。

→ **[@memofs/core の概要](/ja/core/)**

→ **[API リファレンス](/api/core)**

### サーバーをセルフホストする
ホスト型のクラウド版を利用する代わりに、Node.js または Cloudflare Workers 上で MemoFS サーバーをご自身で運用します。

→ **[セルフホスティングの概要](/server/)**

### ホスト型クラウド版（インフラ管理不要）
MemoFS Cloud は、ご自身でインフラを管理することなく、ファイルレプリカ、マネージド MCP エンドポイント、チームワークスペースを提供します。

→ **[MemoFS Cloud](https://memofs.dev)**

## 3 つのメンタルモデル

1. **メモリはデータベースではなく、ファイルです。** コアな事実、ノート、会話履歴、想起インデックス、ナレッジグラフはすべて `.memofs/` ディレクトリ配下に Markdown/JSONL として保持されます — 詳細は [コアコンセプト](/ja/core/concepts) をご覧ください。
2. **すべての機能に決定論的なフォールバックがあります。** 検索、グラフ抽出、リランクはすべて API キーなしで標準動作します（BM25 + ルールベースの解析）。LLM / Embedding アダプターを追加することで機能を強化できます — 詳細は [インテリジェンスの設定](/server/intelligence) をご覧ください。
3. **エージェントに合わせた配布方式。** ライフサイクルフックを備えたエージェント (Claude Code, Codex, opencode) にはメモリが自動注入されます。それ以外の環境は MCP 経由で接続します — 詳細は [MCP の概要](/mcp/) をご覧ください。
