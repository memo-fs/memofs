# MemoFS 1.2.0-beta.1 — Core hardening, recall improvements, and connector enhancements

Third beta, published together at `1.2.0-beta.1` across all 15 packages with the `beta` npm dist-tag. This release tightens memory graph correctness, improves recall reliability across runtimes, adds automatic recall store resolution, expands connector support, and polishes the CLI runtime.

## Core

### Fixed

- Two memory graph nodes can no longer collide and silently overwrite each other.
- Two snapshots created in quick succession can no longer receive the same ID.
- A failed memory write now rolls the graph back to its previous state instead of leaving it partially
  updated.
- A file-locking bug on macOS that could stall the process under heavy concurrent load is resolved.
- Entity matching now rejects short terms (e.g. `"db"`) that previously matched unrelated longer words
  as false positives.
- Combining results from different memory sources no longer silently drops metadata.

### Changed

- Internal caches are now capped so memory growth during long-running sessions stays bounded.
- Search and ranking pipelines are now more consistent so results from both match more reliably.
- Multi-word heading search relevance is improved.
- Recall no longer withholds results when only one search method (keyword or vector) finds matches —
  partial results from a single pipeline are now surfaced.
- Context building is now more reliable across JavaScript runtimes, including web workers.
- Background operations such as indexing and graph updates now support optional structured logging to
  make debugging easier.
- The recall pipeline now automatically resolves the appropriate recall store without requiring manual
  configuration.

## CLI

### Fixed

- Generated configuration files no longer contain an incorrect default schema URL.

### Changed

- Runtime configuration and commander option handling has been refactored to reduce overhead and
  improve startup latency.

## Connectors

### Added

- GitHub Discussions connector now maps the discussion category as a label on the resulting note.

## Agents / Hosted MCP

### Changed

- Documentation has been updated to cover the agent generation and hook commands introduced in
  `1.1.0-beta.1`, including agent rules and getting-started guides.

## Stability

This is a **beta**. The public surface is intended to be stable through `1.0.0`; the `1.2.0-beta.x`
line adds new capabilities and hardens existing ones while preserving the v1 read-by-default server
contract and the beta npm dist-tag.
